Bắt đầu nhanh

Cài đặt lần đầu

Orino Flow cần cài thêm "media core" và môi trường xử lý AI cục bộ trước khi dùng được. Quá trình này chỉ làm một lần.

1
Tải và cài đặt Orino Flow
Tải bản cài đặt phù hợp: Windows 10/11 (.exe) hoặc macOS Apple Silicon (.dmg). Chạy file cài đặt và khởi động ứng dụng.
2
Đăng ký tài khoản
Tạo tài khoản bằng email hoặc Google. Mọi tài khoản mới được dùng thử 1 ngày miễn phí toàn bộ tính năng.
3
Chạy Setup Wizard
Ứng dụng tự nhận diện GPU hoặc CPU, sau đó tải "media core" (ffmpeg) và môi trường xử lý AI cục bộ — khoảng 1.2GB, tùy tốc độ mạng.
4
Kết nối tài khoản AI provider
Vào Cài đặt → Kết nối AI để kết nối Gemini, OpenAI (ChatGPT) hoặc Anthropic (Claude) — cần thiết cho Image Studio, Video Studio, Film Studio và Voice Studio. Google Flow (Veo) kết nối riêng, ngay trong Image Studio, Video Studio, Film Studio hoặc Magic Flow.
Video, âm thanh và phụ đề luôn xử lý cục bộ trên máy bạn — không có dữ liệu nội dung nào được gửi lên server của Orino Flow.
Kết nối AI provider

Bring your own AI account

Orino Flow không tự vận hành hạ tầng AI tạo sinh — bạn kết nối tài khoản của chính mình, tự kiểm soát chi phí và hạn mức sử dụng.

Gemini / Google Flow (Veo)
Dùng cho Image Studio, Video Studio, Film Studio và các node tạo ảnh/video trong Magic Flow.
ChatGPT / Claude
Dùng cho viết logline/synopsis trong Film Studio, và tăng cường văn bản TTS.
1
Chọn nhà cung cấp
Vào Cài đặt → Kết nối AI, chọn Gemini, OpenAI (ChatGPT) hoặc Anthropic (Claude). Google Flow (Veo) không nằm ở đây — nó kết nối riêng, ngay lần đầu bạn dùng trong Image Studio, Video Studio, Film Studio hoặc Magic Flow.
2
Đăng nhập
OpenAI và Anthropic kết nối qua OAuth nhanh gọn; Gemini kết nối qua đăng nhập trình duyệt nhúng. Thông tin xác thực chỉ lưu cục bộ trên máy bạn.
3
Sẵn sàng sử dụng
Sau khi kết nối, provider xuất hiện trong danh sách chọn ở Image Studio, Video Studio, Film Studio và Magic Flow.
Image & Video Studio

Tạo ảnh & video AI

Tạo nội dung đơn lẻ hoặc theo lô, với bảng tác vụ theo dõi từng lượt tạo.

Image Studio
  • Tạo ảnh đơn lẻ hoặc theo lô từ file .txt danh sách prompt
  • Chọn engine: Gemini, Google Flow hoặc ChatGPT
  • Đính kèm ảnh tham chiếu để giữ phong cách/nhân vật
  • Bảng tác vụ: retry, copy prompt, xem trước từng kết quả
Video Studio
  • Text-to-video và image-to-video (chọn khung đầu/cuối)
  • Chạy qua Google Flow / Veo
  • Regenerate theo lô, upscale, ghép các clip đã chọn
  • Dùng video tham chiếu cho chuyển động/phong cách
Pipeline chủ lực

Film Studio — từ ý tưởng đến bộ phim hoàn chỉnh

Idea → Cast → Scenes → Production → Assembly. Đi qua ví dụ dựng một bộ phim ngắn từ đầu đến cuối.

1
Idea
Gõ một câu logline. AI viết synopsis đầy đủ và "style bible" (phong cách hình ảnh, tông màu, nhịp kể chuyện) để giữ nhất quán suốt phim.
2
Cast
AI tự tạo các nhân vật xuyên suốt từ synopsis — bạn có thể chỉnh mô tả, ảnh tham chiếu. Nhân vật được tự động khớp lại ở mọi cảnh xuất hiện sau đó.
3
Scenes
Câu chuyện được chia thành cảnh, mỗi cảnh chia tiếp thành các shot cụ thể (khung hình, hành động, lời thoại).
4
Production
Từng shot được sản xuất: dialogue gốc từ Veo hoặc lồng tiếng bằng TTS. Nếu bạn sửa synopsis hoặc nhân vật sau đó, các shot liên quan tự chuyển sang trạng thái "cũ" (stale) và cần render lại.
5
Assembly
Ghép các shot đã sản xuất thành thành phẩm: chuyển cảnh mượt (cross-fade), burn phụ đề, trộn nhạc nền, xuất nhanh.
Theo dõi trạng thái shot ngay trong màn Production — shot "cũ" (stale) được đánh dấu rõ để bạn biết cần render lại trước khi ghép nối.
Khác biệt

Magic Flow — tự xây pipeline riêng

Trình xây dựng workflow dạng node-graph: kéo-thả và nối các node thành một pipeline sản xuất riêng của bạn.

Prompt node Nhập mô tả văn bản, có thể tham chiếu output của node khác
Prompt Generate node Để AI tự viết hoặc mở rộng prompt dựa trên ngữ cảnh đã nối
Character node Giữ nhất quán ngoại hình nhân vật giữa nhiều lượt tạo
Reference Image / Reference Video node Ảnh/video mẫu để định hướng phong cách hoặc chuyển động
Note node Ghi chú văn bản tự do gắn trên canvas để lên kế hoạch — không chạy
ChatGPT Image / Google Flow Image / Google Flow Video node Nhận input từ Prompt/Reference node, gọi AI provider đã kết nối để tạo
Template library Lưu và tái sử dụng graph đã dựng, hoặc bắt đầu từ template có sẵn
Một graph Magic Flow có thể được build và chạy từ bên ngoài ứng dụng — xem mục MCP server bên dưới.
Voice Studio

TTS, Clone & Thiết kế giọng

Hai engine TTS (Fast / Premium), clone giọng từ mẫu ngắn, thiết kế giọng mới từ mô tả, và thư viện quản lý toàn bộ giọng.

TTS — Fast Tốc độ nhanh, chạy tốt trên máy không GPU mạnh
TTS — Premium Chất lượng giọng cao nhất, tự nhiên nhất
Clone giọng Upload hoặc ghi âm mẫu 3–10 giây, chỉ dùng giọng của bạn hoặc khi có sự đồng ý rõ ràng
Thiết kế giọng Mô tả giới tính, độ tuổi, cao độ, phong cách, accent → AI tổng hợp giọng hoàn toàn mới
Thư viện giọng Nhập/xuất file giọng để sao lưu hoặc chuyển giữa các máy

MCP server — điều khiển app từ AI ngoài

Orino Flow tích hợp sẵn một MCP server (Model Context Protocol). Điều khiển Orino Flow từ AI agent của bạn qua MCP server tích hợp sẵn — build và chạy graph Magic Flow, hoặc kích hoạt tạo ảnh/video, từ một AI agent hoặc CLI bên ngoài.

1
Bật MCP server
Vào Cài đặt → MCP server và bật công tắc. Server chạy cục bộ (localhost) trên máy bạn.
2
Kết nối agent/CLI của bạn
Trỏ client MCP (Claude Desktop, một agent tự viết, hoặc CLI hỗ trợ MCP) đến địa chỉ server hiển thị trong màn Cài đặt.
3
Điều khiển từ xa
Build/chạy graph Magic Flow, kích hoạt tạo ảnh hoặc video — tất cả từ agent ngoài, không cần mở giao diện app.
Kết nối MCP chạy cục bộ — chúng tôi không trung chuyển hay ghi log nội dung lệnh gửi qua MCP server.
