Getting started

First-time setup

Orino Flow needs to install a "media core" and a local AI processing environment before it's ready to use. This only happens once.

1
Download and install Orino Flow
Download the right build: Windows 10/11 (.exe) or macOS Apple Silicon (.dmg). Run the installer and launch the app.
2
Create an account
Sign up with email or Google. Every new account gets a 1-day free trial with every feature enabled.
3
Run the Setup Wizard
The app auto-detects GPU or CPU, then downloads the "media core" (ffmpeg) and a local AI processing environment — about 1.2GB, depending on your connection.
4
Connect an AI provider account
Go to Settings → AI Connection to connect Gemini, OpenAI (ChatGPT), or Anthropic (Claude) — required for Image Studio, Video Studio, Film Studio, and Voice Studio. Google Flow (Veo) connects separately, right inside Image Studio, Video Studio, Film Studio, or Magic Flow.
Video, audio and subtitles are always processed locally on your machine — no content data is ever sent to Orino Flow's servers.
Connect an AI provider

Bring your own AI account

Orino Flow does not operate its own generative-AI infrastructure — you connect your own account and control your own usage and cost.

Gemini / Google Flow (Veo)
Used for Image Studio, Video Studio, Film Studio, and the image/video generation nodes in Magic Flow.
ChatGPT / Claude
Used for writing loglines/synopses in Film Studio, and enhancing TTS text.
1
Choose a provider
Go to Settings → AI Connection, and pick Gemini, OpenAI (ChatGPT), or Anthropic (Claude). Google Flow (Veo) isn't listed here — it connects separately, the first time you use it inside Image Studio, Video Studio, Film Studio, or Magic Flow.
2
Sign in
OpenAI and Anthropic connect via a quick OAuth sign-in; Gemini connects through an embedded browser login. Credentials are stored locally on your machine only.
3
Ready to use
Once connected, the provider appears in the picker inside Image Studio, Video Studio, Film Studio, and Magic Flow.
Image & Video Studio

Generate AI images & video

Create content one at a time or in batch, with a task table tracking every generation.

Image Studio
  • Generate single images or batch from a .txt prompt list
  • Choose an engine: Gemini, Google Flow, or ChatGPT
  • Attach reference images to keep style/characters consistent
  • Task table: retry, copy prompt, preview each result
Video Studio
  • Text-to-video and image-to-video (choose start/end frame)
  • Runs through Google Flow / Veo
  • Batch regenerate, upscale, concatenate selected clips
  • Use reference videos for motion/style guidance
Flagship pipeline

Film Studio — from idea to finished film

Idea → Cast → Scenes → Production → Assembly. Walk through producing a short film from start to finish.

1
Idea
Type a one-line logline. AI writes a full synopsis and a "style bible" (visual style, tone, pacing) to keep the whole film consistent.
2
Cast
AI auto-creates recurring characters from the synopsis — you can edit descriptions and reference images. Characters are auto-matched wherever they reappear.
3
Scenes
The story is broken into scenes, and each scene into specific shots (framing, action, dialogue).
4
Production
Each shot is produced: native Veo dialogue or TTS voice-over. If you later edit the synopsis or a character, affected shots automatically flip to "stale" and need re-rendering.
5
Assembly
Produced shots are assembled into the finished cut: cross-fades, subtitle burn-in, music mixing, quick export.
Track shot status right in the Production screen — "stale" shots are clearly flagged so you know what needs re-rendering before assembly.
Differentiator

Magic Flow — build your own pipeline

A node-graph workflow builder: drag, drop, and connect nodes into your own custom production pipeline.

Prompt node Enter a text description, optionally referencing another node's output
Prompt Generate node Lets AI write or expand a prompt automatically from the connected context
Character node Keeps a character's appearance consistent across multiple generations
Reference Image / Reference Video node Sample image or video to steer the style or motion of a generation
Note node Freeform text note pinned to the canvas for planning — doesn't run
ChatGPT Image / Google Flow Image / Google Flow Video node Takes input from Prompt/Reference nodes, calls your connected AI provider to generate
Template library Save and reuse graphs you build, or start from a ready-made template
A Magic Flow graph can be built and run from outside the app — see the MCP server section below.
Voice Studio

TTS, cloning & voice design

Two TTS engines (Fast / Premium), voice cloning from a short sample, designing a new voice from a description, and a library to manage them all.

TTS — Fast Fast, runs well on machines without a powerful GPU
TTS — Premium Highest quality, most natural-sounding voice
Voice cloning Upload or record a 3–10s sample, using only your own voice or with explicit consent
Voice design Describe gender, age, pitch, style, accent → AI synthesizes a brand-new voice
Voice library Import/export voice files to back up or move between machines
Advanced · Technical differentiator

MCP server — control the app from an external AI

Orino Flow ships with a built-in MCP server (Model Context Protocol). Control Orino Flow from your own AI agent through its built-in MCP server — build and run Magic Flow graphs, or trigger image/video generation, from an external AI agent or CLI.

1
Enable the MCP server
Go to Settings → MCP server and flip the switch. The server runs locally (localhost) on your machine.
2
Point your agent/CLI at it
Point an MCP client (Claude Desktop, a custom agent, or any MCP-capable CLI) at the server address shown in Settings.
3
Control it remotely
Build/run Magic Flow graphs, or trigger image/video generation — all from an external agent, with no need to open the app's UI.
The MCP connection runs locally — we do not relay or log the content of commands sent through the MCP server.
Account & plans

Subscriptions & billing

Every new account gets a 1-day trial. Upgrade right in the app from the Account screen.

Trial — 1 day Every feature enabled, daily usage limits apply
Monthly / 3-month / 6-month Unlimited features, manual renewal, 1 device — see current prices on the Pricing section or in the app
Payment Visa/Mastercard or PayPal — activates automatically after payment
Your plan only affects usage limits — it has no bearing on the fact that your video is processed locally.
